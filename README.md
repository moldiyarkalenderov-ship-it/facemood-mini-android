# FaceMood Mini Android APK

Бұл Android қосымша `https://facemood-mini.streamlit.app` веб-өнімін WebView ішінде ашады және камера рұқсатын береді.

## GitHub арқылы APK құрастыру

1. Жаңа public репозиторий ашыңыз: `facemood-mini-android`.
2. Осы жобаның ішіндегі барлық файлдар мен бумаларды репозиторий түбіріне жүктеңіз.
3. **Actions** бөліміне кіріңіз.
4. **Build FaceMood Mini APK** workflow-ын таңдаңыз.
5. **Run workflow** басыңыз.
6. Жасыл белгі шыққан соң орындалған workflow-ты ашыңыз.
7. **Artifacts** ішінен `FaceMood-Mini-APK` файлын жүктеңіз.
8. ZIP архивіндегі `app-debug.apk` файлын Android телефонға орнатыңыз.

## Қауіпсіздік

- Қосымша тек камера және интернет рұқсатын сұрайды.
- Камера веб-қосымшадағы «Take Photo» қызметіне беріледі.
- Бұл алғашқы debug APK, Google Play-ге жариялауға арналған қолтаңбалы AAB емес.
